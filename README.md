# 🇬🇷 Kouzina

**Kouzina** is a full-stack web application for a traditional Greek restaurant based in Braunschweig, Germany.
Built using Java Spring Boot, PostgreSQL, and Thymeleaf, it allows users to view a menu of authentic Greek dishes and (future feature) make table reservations online.

---

## 🍽 Features

- View a dynamic restaurant menu from the database
- Organized dish categories (starters, mains, desserts)
- Styled front-end using Thymeleaf
- (Coming soon) Reservation system
- (Coming soon) Admin dashboard for managing menu items

---

## 🛠 Tech Stack

- **Backend**: Java 23, Spring Boot 3, Spring Data JPA
- **Database**: PostgreSQL
- **Frontend**: Thymeleaf (HTML templating)
- **Build Tool**: Maven
- **Dev Tools**: Spring DevTools, IntelliJ IDEA
